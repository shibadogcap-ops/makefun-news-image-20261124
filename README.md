# makefun-news-image-20261124

A tiny software printing press: one `main.py` that rasterises a broadsheet
front page for Tuesday, 24 November 2026 — lead story: Nvidia's board
reinstates Jensen Huang as CEO — and writes it as `entry.png`. It uses only
Python's standard library: its own PNG encoder, rasteriser and stroke font,
with no dependencies.

When run by the grader it writes `/output/entry.png`; locally it writes
`$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
